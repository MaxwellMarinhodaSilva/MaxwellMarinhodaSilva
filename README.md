## Projetos em destaque

### [ConsultaSeloDigital](https://github.com/MaxwellMarinhodaSilva/ConsultaSeloDigital)

Aplicação desktop que centraliza consultas individuais e em lote de selos digitais nos serviços públicos do TJPB, TJRN e TJPE. Importa dados em TXT, CSV e XLSX, acompanha o processamento, mantém histórico e exporta resultados em PDF e XLSX.

**Tecnologias comprovadas:** Java 21, Swing, Maven, Java HTTP Client, Jackson, Apache POI, PDFBox, ZXing e FlatLaf.

### [IndicadorReal](https://github.com/MaxwellMarinhodaSilva/IndicadorReal)

Aplicação desktop que interpreta registros de erro em TXT ou texto colado, cruza matrículas com dados em JSON e corrige o campo `TIPOENVIO`. Preserva o arquivo original e gera um novo JSON, relatório e log da execução.

**Tecnologias comprovadas:** Java 21, Swing, Maven, Jackson, JSON, expressões regulares e FlatLaf.

### [Monitoramento de Temperatura e Umidade via SNMP](https://github.com/MaxwellMarinhodaSilva/arduino-snmp-zabbix-dht22)

Agente SNMP em Arduino que mantém leituras periódicas de temperatura e umidade e as disponibiliza ao Zabbix por OIDs personalizadas, usando Ethernet Shield W5100 e sensor DHT22.

**Tecnologias comprovadas:** Arduino, C++, SNMP, Zabbix, Ethernet W5100, DHT22 e Agentuino.
