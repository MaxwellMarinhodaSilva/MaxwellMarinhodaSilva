## Projeto em destaque

### [Monitoramento de Temperatura e Umidade via SNMP](https://github.com/MaxwellMarinhodaSilva/arduino-snmp-zabbix-dht22)

Projeto pessoal para coleta de temperatura e umidade com Arduino, Ethernet Shield W5100 e sensor DHT22, integrado ao Zabbix por SNMP.

O código em C++ implementa um agente SNMP, mantém leituras periódicas do sensor em memória e disponibiliza OIDs personalizadas para temperatura e umidade.

**Tecnologias:** Arduino, C++, SNMP, Zabbix, Ethernet W5100 e DHT22.
