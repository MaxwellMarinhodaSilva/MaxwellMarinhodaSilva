## 🚀 Projetos em destaque

### ConsultaSeloDigital

Aplicação desktop em Java 21 para consultas individuais e em lote de selos digitais nos serviços públicos do TJPB, TJRN e TJPE. Permite importação de arquivos TXT, CSV e XLSX, mantém histórico e exporta resultados em PDF e XLSX.

**Tecnologias:** `Java 21` `Swing` `HTTP Client` `Jackson` `Apache POI` `PDFBox` `ZXing`

[![Ver ConsultaSeloDigital](https://img.shields.io/badge/Ver_repositório-ConsultaSeloDigital-0A66C2?style=flat-square&logo=github&logoColor=white)](https://github.com/MaxwellMarinhodaSilva/ConsultaSeloDigital)

### IndicadorReal

Aplicação desktop em Java 21 que interpreta registros de erro em TXT ou texto colado, cruza matrículas com arquivos JSON e corrige o campo `TIPOENVIO`. Gera um novo JSON, relatório TXT e log de execução.

**Tecnologias:** `Java 21` `Swing` `Maven` `FlatLaf` `Jackson` `JSON`

[![Ver IndicadorReal](https://img.shields.io/badge/Ver_repositório-IndicadorReal-0A66C2?style=flat-square&logo=github&logoColor=white)](https://github.com/MaxwellMarinhodaSilva/IndicadorReal)

### Monitoramento de Temperatura e Umidade via SNMP

Agente SNMP em Arduino para disponibilizar leituras de temperatura e umidade ao Zabbix, utilizando Ethernet Shield W5100 e sensor DHT22.

**Tecnologias:** `Arduino` `C++` `SNMP` `Zabbix` `W5100` `DHT22`

[![Ver projeto SNMP e Zabbix](https://img.shields.io/badge/Ver_repositório-SNMP_+_Zabbix-0A66C2?style=flat-square&logo=github&logoColor=white)](https://github.com/MaxwellMarinhodaSilva/arduino-snmp-zabbix-dht22)
